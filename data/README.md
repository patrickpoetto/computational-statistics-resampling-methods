# Data

All files here are generated by `../scripts_build_data.R` (run it once from
the repository root before running either analysis script). See the main
[README](../README.md#data) for the full explanation of why these exist
and what each one is.

| File | Status | Rows | Notes |
|---|---|---|---|
| `housing.csv` | Real | 506 | `MASS::Boston`, no header, UCI column order (`CRIM`…`LSTAT`, response last, renamed `y` by the script). |
| `ozone.csv` | Real | 203 (complete cases of 366) | `mlbench::Ozone`, response (`V4`) in column 1, header `V4..V13`. |
| `bike_sharing.csv` | Real | 729 | Public UCI bike-sharing daily counts, leakage/id columns dropped. Used only in script 1's short "bagging a stable OLS" example. |
| `boardgames.csv` | **Synthetic stand-in** | 6000 | Not the real coursework data — generated from a designed correlation structure. See caveat in the main README. |
| `spotify.csv` | **Synthetic stand-in** | 2072 | Not the real coursework data — generated only so the permutation-test / multiple-testing code has a `first_auth` + `pop` to run against. |

Do not treat the synthetic files' numeric results as the original report's
findings — they exist to verify the *code* runs correctly, not to
reproduce the original *data analysis*.
